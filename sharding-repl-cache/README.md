# Инструкция по запуску


## Запуск и инициализация

Для запуска и конфигурации приложения необходимо выполнить следующую последовательность действий:

1. Перейти в директорию `sharding-repl-cache`
```
cd sharding-repl-cache
```
2. Запустить docker-контейнеры:
```
docker compose up -d
```
3. Запустить скрипт инициализации БД:
```
bash init_db.sh
```

## Просмотр кол-ва документов в БД

Для просмотра общего кол-ва документов в БД и в отдельных шардах, а также кол-ва реплик необходимо выполнить соответсвующие HTTP-запросы к API:
```
# Общее кол-во документов в БД
curl http://localhost:8080/helloDoc/count

# Кол-во документов в shard1
curl http://localhost:8080/helloDoc/count/shard1

# Кол-во документов в shard2
curl http://localhost:8080/helloDoc/count/shard2

# Кол-во реплик в shard1
curl http://localhost:8080/shard1/replica-count

# Кол-во реплик в shard2
curl http://localhost:8080/shard2/replica-count
```

## Проверка работы кеша

Для проверки работы кеша необходимо несколько раз выполнить запрос

```
time curl http://localhost:8080/helloDoc/users
```

В первый раз он покажет время выполнения чуть больше секунды, а в последующие 60 секунд <100мс
